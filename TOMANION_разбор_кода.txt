================================================================================
  TOMANION — разбор кода игры (что делает каждая часть)
  Проект: tomato_onion_game
  Файлы: 15 Python-модулей + assets (картинки, музыка)
  Обновлено: магазин, монеты, история intro/outro, аксессуары
================================================================================

КАК ЧИТАТЬ ЭТОТ ДОКУМЕНТ
------------------------
• Маленькие файлы разобраны почти построчно.
• Большие файлы (game.py, entities.py, levels.py, pixel_art.py, menu.py)
  разобраны по блокам с указанием номеров строк.
• levels.py: уровни 1–30 устроены одинаково (if n == 1: ... elif n == 2: ...),
  поэтому каждый уровень отдельно не расписан — описана общая схема.


================================================================================
main.py — точка входа (4 строки)
================================================================================

Строка 1:  from game import run_game
           — импортирует функцию запуска игры из game.py.

Строка 3:  if __name__ == "__main__":
           — код ниже выполняется только при прямом запуске файла
             (python main.py или двойной клик по exe).

Строка 4:      run_game()
           — запускает меню, историю, игровой цикл и финал.


================================================================================
constants.py — константы (размер экрана, физика, цвета)
================================================================================

Строки 1–5:   WIDTH=960, HEIGHT=540 — размер окна в пикселях.
              FPS=60 — кадров в секунду.
              GRAVITY=0.55 — сила притяжения для прыжков.
              PIXEL_SCALE=3 — масштаб пиксель-арта.

Строки 7–29:  Цвета в формате RGB (кортеж из трёх чисел):
              OUTLINE — контур объектов.
              BG, BG_TOP — фон неба/задника.
              PLATFORM* — коричневые платформы.
              FRAGILE* — хрупкие плиты.
              METAL* — металл (стены, двери).
              GOAL* — зелёная цель уровня.
              WHITE, YELLOW, CYAN, RED* — UI и герои.
              ONION_* — цвета Лука.
              JUNK* — цвета врагов-фастфуда.

Строки 31–33: TOMATO_COLOR, ONION_COLOR, ONION_GREEN — алиасы цветов героев.

Строка 35:    LEVELS_TOTAL = 30 — всего уровней в игре.


================================================================================
paths.py — пути к файлам (для .exe и для python)
================================================================================

Строки 1–2:   import sys, Path — системные пути.

Строки 5–9:   app_dir() — папка, где лежит exe или исходники.
              Если игра собрана в exe (frozen), берётся папка с exe.
              Иначе — папка с paths.py.
              Здесь сохраняются progress.json и settings.json.

Строки 12–16: resource_dir() — папка с ресурсами (assets, музыка).
              В exe ресурсы распаковываются во временную папку _MEIPASS.


================================================================================
progress.py — сохранение прогресса, монет и аксессуаров (~128 строк)
================================================================================

Строка 5:     PROGRESS_PATH — путь к progress.json рядом с exe/игрой.

Строки 8–24:  _load_data() / _save_data() — чтение и запись JSON.

Строки 27–59: load_progress(), load_current_level(), save_progress(),
              save_current_level(), unlock_level() — открытые уровни.

Строки 62–76: load_coins(), save_coins(), add_coins(delta)
              — баланс монет (для магазина).

Строки 79–86: load_owned() — список купленных id аксессуаров.

Строки 89–94: load_equipped() — что надето на Томате и Луке:

               — покупка: проверка монет, списание, добавление в owned.

Строки 113–125: equip_item(hero, item_id) — надеть или снять (None).

Строки 128–132: toggle_equip(item_id, hero) — переключить надет/снят.

================================================================================
entities.py — игровые объекты (~765 строк)
================================================================================

--- Player (109+) — Томат и Лук ---

Строка 130:    self.accessory = None — id надетого предмета из магазина.

Строки 135–137: max_jumps=2 для Томата (двойной прыжок по W).

  Томат (R): таран + щит.

             tackle_hit_cooldown — не более одного урона тараном за раз.

--- Trampoline, Arrow, Tile, враги (Fries, Cola, Donut, Turret) ---


================================================================================
level_transition.py — анимация между уровнями
================================================================================

Анимация «плиток»: Томат улетает на ракете, открывается следующий уровень.
Enter — пропуск. POST_EXIT_FRAMES — пауза после улёта.


================================================================================
levels.py — генерация всех 30 уровней (~876 строк)
================================================================================

build_level(n) — платформы, батуты, враги, боссы (10/15/20/25/30),
cola_gaps, fragile-платформы, клетка Лука (ур.5), coop с 6-го.

_space_enemies(min_gap=72) — разводит врагов.
_boss_fire_interval(n) — интервал огня босса (5.0 → 3.0 сек).


================================================================================
game.py — игровой цикл (~660 строк)
================================================================================

Строка 17:    COINS_PER_KILL = 100 — монеты за убитого врага.

Строки 72–73: self.coins = load_coins() — баланс из progress.json.
              self.equipped = load_equipped() — надетые аксессуары.

Строки 137–145: _apply_cosmetics() — accessory на tomato/onion после load_level.

Строка 145:   _flush_coins() — save_coins при выходе в меню / победе.

handle_input:
  Esc → menu + сохранить монеты и уровень.
  E → смена героя, R/T → супер-способности.
  Enter на complete → return "victory" (финал истории).

update:
  +100 монет за каждого убитого врага в кадре смерти.
  goal_lock пока живы враги/босс.
  level_transition, win/gameover, физика, бой.

_draw_hud: строка «Монеты: N».

run_game():
  run_menu() → если старт с ур.1 → run_intro() → Game → run()
  end == "victory" → run_outro().


================================================================================
menu.py — главное меню и магазин (~573 строки)
================================================================================

_main_buttons: Играть, Выбор уровня, Магазин, Настройки, Выход.

_draw_main: баланс монет, герои с надетыми аксессуарами на фоне.

screen_name == "shop":
  _draw_shop() — 4 товара по 500 монет, превью, купить/надеть.
  _shop_action() — purchase_item + equip_item / toggle_equip.
  ↑↓ — выбор, Enter — действие, Esc — назад.

_refresh_shop_state() — load_coins, load_owned, load_equipped.


================================================================================
validate_levels.py — проверка уровней (для разработки)
================================================================================

check_level(n) — build_level(n) и проверки spawn/goal/enemies/boss.
main() — все 30 уровней; печатает OK/FAIL.

================================================================================
КРАТКАЯ СХЕМА ЗАПУСКА
================================================================================

main.py → run_game()
            → run_menu()  (магазин, монеты)
            → run_intro() если уровень 1
            → Game(settings, level)  (монеты, аксессуары, уровни)
            → run_outro() после победы на 30-м

Сборка exe:
  cd tomato_onion_game
  python -m PyInstaller TOMANION.spec --distpath Downloads --noconfirm
